# لقطة — Laqta

محرر فيديو يعمل بالكامل داخل المتصفح على الكمبيوتر والجوال، بأسلوب تطبيقات InShot.

- قص وتقسيم ودمج المقاطع والصور، والتحكم بالسرعة والصوت
- نصوص بخطوط عربية وحركات، وسحبها مباشرة على المعاينة
- موسيقى وتعليق صوتي مع ظهور واختفاء تدريجي
- فلاتر جاهزة وضبط السطوع والتباين والتشبع والدفء
- مقاسات 9:16 و1:1 و4:5 و16:9 مع خلفية ضبابية أو ملونة
- انتقالات بين المقاطع، وتراجع وإعادة
- تصدير MP4 أو WebM بجودة 480p إلى 1080p
- واجهة عربية مع زر للإنجليزية، ووضع فاتح وداكن

كل المعالجة تتم على جهاز المستخدم ولا تُرفع الملفات لأي خادم.

## التشغيل
الملف `index.html` مستقل بالكامل. لتشغيله على GitHub Pages:
Settings → Pages → Branch: `main` / root.
